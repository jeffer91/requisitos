# Exportaciones previstas

Esta carpeta reserva el desarrollo futuro de Word (.docx) y PDF del informe. No hay exportación habilitada mientras falten las secciones genéricas, las verificaciones documentales, las fuentes de datos o el formato aprobado.

Respetar la guía institucional INF v1.1 para la portada y APA 7 para texto, citas, tablas, figuras y referencias. La paginación será automática, y el código documental nunca se inventará.

Evitar producir un archivo formal con texto pendiente, resultados no verificados o referencias inexistentes.
